Booking Status State Machine

PENDING → CONFIRMED → COMPLETED
   │          │
   └──→ CANCELLED ←──┘

• confirm: PENDING → CONFIRMED（管理员操作）
• complete: CONFIRMED → COMPLETED（专家操作）
• cancel: PENDING/CONFIRMED → CANCELLED（客户 24h 前 / 管理员无限制）
外部依赖：
• customer_id — 逻辑外键，引用 BE1 Users 表
• specialist_id — 逻辑外键，引用 BE3 Specialists 表
• time_slot_id — 物理外键，引用 time_slots.id
并发控制：悲观锁 (SELECT FOR UPDATE) + 乐观锁 (version 字段)
