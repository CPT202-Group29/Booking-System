BE2 Booking Module — ERD

erDiagram time_slots { bigint id PK "自增主键" bigint specialist_id "逻辑FK → BE3" datetime start_time datetime end_time boolean is_available int version "乐观锁" datetime created_at } bookings { bigint id PK "自增主键" bigint customer_id "逻辑FK → BE1" bigint specialist_id "逻辑FK → BE3" bigint time_slot_id FK "物理FK → time_slots" varchar status "PENDING|CONFIRMED|CANCELLED|COMPLETED" varchar topic "咨询主题" varchar notes "备注" decimal charge_amount "费用" varchar cancel_reason "取消原因" datetime created_at datetime updated_at } time_slots ||--o{ bookings : "time_slot_id (1:N)"
状态机:
PENDING → CONFIRMED → COMPLETED
│ │
└──→ CANCELLED ←──┘

外部依赖:
• customer_id — BE1 用户模块提供
• specialist_id — BE3 专家管理模块提供

约束:
• end_time > start_time (time_slots)
• status IN ('PENDING','CONFIRMED','CANCELLED','COMPLETED') (bookings)
• charge_amount >= 0 (bookings)
• time_slot_id 有数据库外键约束，删时段前须先处理关联 booking
• version 字段用 @Version 乐观锁，防并发重复预订

索引:
• time_slots: specialist_id, is_available
• bookings: customer_id, specialist_id, status, time_slot_id
